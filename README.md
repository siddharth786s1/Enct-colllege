# ENCT College Website

This is a comprehensive web application for ENCT College featuring:

## Features
- Information about the college, its founders, and academic programs
- Admissions information and application process
- Student life details
- Faculty profiles
- News and Events
- Alumni network
- Contact information

## Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Java (Servlets, JSP)
- Database: MySQL
- Build Tool: Maven

## Project Structure
- `/src/main/java`: Java backend code
- `/src/main/webapp`: Web resources (HTML, CSS, JS)
- `/src/main/webapp/views`: JSP pages for different sections
- `/src/main/webapp/resources`: Static resources

## How to Run
1. Clone the repository
2. Configure the database connection
3. Deploy to a servlet container (like Tomcat)
4. Access via browser at http://localhost:8080/enct-college
